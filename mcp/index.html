01Ce que l’agent peut faire

Une seule table de définitions (schémas JSON) sert à la fois window.BinksyAPI et les outils WebMCP. Toutes les méthodes sont asynchrones et renvoient du JSON ; une erreur est rejetée avec { code, message }. Liste à jour : await BinksyAPI.describe().

Outil WebMCPMéthodeCe qu’il fait
motionlab_describeBinksyAPI.describe()Décrit l’app et la liste des outils.
motionlab_get_stateBinksyAPI.getState()Lit l’état : modèle, format, durée, emplacements, fond, textes, logo, images clés.
motionlab_lister_modelesBinksyAPI.listTemplates()Liste / cherche les 258 modèles.
motionlab_lire_modeleBinksyAPI.getTemplate()Réglages d’un modèle (chemins, bornes, options).
motionlab_choisir_modeleBinksyAPI.selectTemplate()Choisit le modèle.
motionlab_choisir_formatBinksyAPI.setRatio()Format du cadre (16:9, 4:3, 1:1, 4:5, 3:4, 9:16).
motionlab_dureeBinksyAPI.setDuration()Durée de la boucle (2 à 40 s).
motionlab_nombre_imagesBinksyAPI.setImageCount()Nombre d’images utilisées par le modèle.
motionlab_reglerBinksyAPI.setValues()Règle des valeurs par chemin (tp.…, bg.…, logo.…, tx.…).
motionlab_fondBinksyAPI.setBackground()Fond couleur, dégradé ou image fournie.
motionlab_importerBinksyAPI.importer()Importe images / vidéos dans les emplacements, ou un projet .json.
motionlab_viderBinksyAPI.clearSlots()Vide des emplacements.
motionlab_exemplesBinksyAPI.loadExamples()Remet les visuels d’exemple (tests seulement).
motionlab_ajouter_texteBinksyAPI.addText()Ajoute un calque texte (texte fourni / validé).
motionlab_supprimer_texteBinksyAPI.removeText()Supprime un calque texte.
motionlab_logoBinksyAPI.setLogo()Pose, place, règle ou retire le logo fourni.
motionlab_image_cleBinksyAPI.setKeyframe()Pose / modifie / retire une image clé à un instant (0–1).
motionlab_tempsBinksyAPI.setTime()Tête de lecture et lecture / pause.
motionlab_exporterBinksyAPI.exporter()Exporte MP4, WebM, PNG ou projet .json (base64).
motionlab_enregistrer_projetBinksyAPI.saveProject()Enregistre le projet et ses médias dans le navigateur.
motionlab_lister_projetsBinksyAPI.listProjects()Liste les projets enregistrés.
motionlab_ouvrir_projetBinksyAPI.openProject()Ouvre un projet enregistré (avec ses médias).
motionlab_resetBinksyAPI.reset()Remet la session par défaut (confirm: true après accord).

Les médias importés ne sont pas gardés dans la session automatique (seuls les réglages le sont) : appelle motionlab_enregistrer_projet pour les retrouver au rechargement (motionlab_ouvrir_projet). Les visuels d’exemple sont marqués example: true dans get_state : ne les livre jamais.

02Connexion A — agent intégré au navigateur (WebMCP)

WebMCP est une proposition de standard encore expérimentale. Dans un Chrome récent (146 ou plus), active le drapeau chrome://flags/#enable-webmcp-testing, relance Chrome, puis ouvre https://motion.binksdesign.com/app.html. Les outils ci-dessus s’enregistrent tout seuls (document.modelContext.registerTool, avec repli sur les premières formes navigator.modelContext / provideContext) et l’agent du navigateur ou une extension compatible les voit. L’API évolue : en cas de doute, vérifie la documentation Chrome for Developers. Sans WebMCP, rien ne change : window.BinksyAPI reste disponible.

03Connexion B — Claude Code, Codex, Hermes, OpenCode

Ces agents pilotent un navigateur local via un serveur MCP standard : Playwright MCP. Ajoute-le à la configuration MCP de ton agent :

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": [
        "@playwright/mcp@latest"
      ]
    }
  }
}

(Claude Code : claude mcp add playwright npx @playwright/mcp@latest.) Demande ensuite à l’agent d’ouvrir https://motion.binksdesign.com/app.html et d’appeler window.BinksyAPI avec l’outil d’évaluation JavaScript (browser_evaluate). Exemples :

Découvrir les outils

await BinksyAPI.ready();
(await BinksyAPI.describe()).tools.map(t => t.name);

Importer les visuels fournis (base64) et choisir un modèle

await BinksyAPI.importer({ clearFirst: true, files: [
  { name: "visuel-01.jpg", type: "image/jpeg", dataBase64: "<base64 du fichier fourni>" },
  { name: "visuel-02.jpg", type: "image/jpeg", dataBase64: "<base64>" }
] });
await BinksyAPI.setRatio({ ratio: "9:16" });
await BinksyAPI.selectTemplate({ id: "cover-flow" });
await BinksyAPI.setDuration({ seconds: 10 });

Exporter la vidéo MP4 1080p et garder le projet

const { files } = await BinksyAPI.exporter({ format: "mp4", resolution: 1080, fps: 30 });
files[0].name; // sans-titre.mp4, dataBase64 = la vidéo
await BinksyAPI.saveProject({ name: "<nom donné par l’utilisateur>" });

04Prompt prêt à copier

Ouvre https://motion.binksdesign.com/app.html avec le navigateur (Playwright MCP). Attends await window.BinksyAPI.ready(), lis await BinksyAPI.describe(), puis utilise uniquement window.BinksyAPI (via browser_evaluate) : vide les emplacements, importe les visuels que je te donne (base64), propose-moi 3 modèles adaptés à un Reel 9:16 de 10 s, et après mon choix exporte la vidéo MP4 1080p. N’invente aucun texte, logo ni couleur ; rien ne doit être envoyé en ligne.

05Rien n’est envoyé

  • Tout se passe dans l’onglet : aucun serveur, aucune base de données, aucune requête réseau ajoutée. Tes fichiers ne quittent jamais le navigateur.
  • Pas de compte, pas de clé API : l’API n’en lit ni n’en écrit aucune.
  • Chaque action passe par la même logique que l’interface : l’écran se met à jour et l’enregistrement automatique (IndexedDB) garde tout au rechargement.
  • L’agent ne doit jamais inventer de logo, de couleur ou de nom de client : il manipule ce que l’utilisateur fournit.

ENAgent API (short)

Import the user’s visuals, pick one of 258 templates, set format, duration, background, texts, logo and keyframes, then export MP4, WebM or PNG. The app exposes window.BinksyAPI (async methods, JSON results, errors rejected as { code, message }) and registers the same tools through WebMCP when the browser supports it (Chrome 146+ with chrome://flags/#enable-webmcp-testing; still experimental).

  • motionlab_describe (BinksyAPI.describe) — Describes the app and its tools.
  • motionlab_get_state (BinksyAPI.getState) — Reads the state.
  • motionlab_lister_modeles (BinksyAPI.listTemplates) — Lists / searches the 258 templates.
  • motionlab_lire_modele (BinksyAPI.getTemplate) — A template’s settings.
  • motionlab_choisir_modele (BinksyAPI.selectTemplate) — Picks the template.
  • motionlab_choisir_format (BinksyAPI.setRatio) — Frame format.
  • motionlab_duree (BinksyAPI.setDuration) — Loop duration (2–40 s).
  • motionlab_nombre_images (BinksyAPI.setImageCount) — Number of images used.
  • motionlab_regler (BinksyAPI.setValues) — Sets values by path.
  • motionlab_fond (BinksyAPI.setBackground) — Colour, gradient or image background.
  • motionlab_importer (BinksyAPI.importer) — Imports images / videos into slots, or a .json project.
  • motionlab_vider (BinksyAPI.clearSlots) — Empties slots.
  • motionlab_exemples (BinksyAPI.loadExamples) — Restores the example visuals (tests only).
  • motionlab_ajouter_texte (BinksyAPI.addText) — Adds a text layer (provided / approved text).
  • motionlab_supprimer_texte (BinksyAPI.removeText) — Removes a text layer.
  • motionlab_logo (BinksyAPI.setLogo) — Sets, places or removes the provided logo.
  • motionlab_image_cle (BinksyAPI.setKeyframe) — Adds / edits / removes a keyframe (0–1).
  • motionlab_temps (BinksyAPI.setTime) — Playhead and play / pause.
  • motionlab_exporter (BinksyAPI.exporter) — Exports MP4, WebM, PNG or .json project (base64).
  • motionlab_enregistrer_projet (BinksyAPI.saveProject) — Saves the project and its media in the browser.
  • motionlab_lister_projets (BinksyAPI.listProjects) — Lists saved projects.
  • motionlab_ouvrir_projet (BinksyAPI.openProject) — Opens a saved project (with media).
  • motionlab_reset (BinksyAPI.reset) — Resets the session (confirm: true).
